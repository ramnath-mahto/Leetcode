# 198. House Robber

🔗 [LeetCode Problem](https://leetcode.com/problems/house-robber/description/)

**Difficulty:** Medium  
**Topic:** Dynamic Programming  
**Language:** C++

## Approach
For each house, choose between robbing the current house plus the best amount from two houses before, or skipping the current house.

## Complexity
- Time: O(n)
- Space: O(1)
