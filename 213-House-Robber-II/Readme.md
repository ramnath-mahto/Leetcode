# #0213 — House Robber II

🔗 **LeetCode:** [House Robber II](https://leetcode.com/problems/house-robber-ii/)

**Difficulty:** 🟡 Medium

**Topic:** Dynamic Programming, Array

---

## Problem

You are given an array where each element represents the amount of money in a house.

The houses are arranged in a **circle**, so the first house and the last house are also neighbors.

You cannot rob two adjacent houses because the security system will alert the police.

Return the **maximum amount of money** you can rob without robbing two adjacent houses.

For example, for `nums = [2,3,2]`, you cannot rob the first and last houses together because they are adjacent. The maximum amount you can rob is `3`.

The main challenge is handling the circular arrangement of the houses.
